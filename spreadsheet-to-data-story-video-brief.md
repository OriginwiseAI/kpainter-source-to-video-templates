# Spreadsheet-to-Data-Story Video Brief

Use this brief to turn a spreadsheet into a careful explanation of a trend, comparison, forecast, or operating decision.

## Narrative structure

| Question | Answer |
| --- | --- |
| What changed, compared with what? | |
| Why does it matter to this viewer? | |
| Which chart or table supports the claim? | |
| What should not be inferred from the data? | |
| What decision or follow-up is appropriate? | |

## Visual beats

1. Define the measure and comparison period.
2. Show the relevant pattern, not every column.
3. Add the operational, financial, or customer context.
4. State the uncertainty or decision condition.
5. Direct the viewer to the current dashboard or report.
